🌱 Krishi Mitra AI

Smart Agricultural Assistance for Farmers

Krishi Mitra AI is a web-based agricultural assistance prototype designed to make useful farming information more accessible to farmers. It aims to support smarter agricultural decisions through a simple interface, crop advisory features, and regional language accessibility.

🌐 Live Website: "Open Krishi Mitra AI" (https://github.com/YOUR-USERNAME/krishi-mitra-ai.git)

📌 Project Overview

Agriculture is an important source of livelihood for many people. Farmers may face challenges accessing understandable agricultural guidance, choosing suitable crops, and using digital tools in their preferred language.

Krishi Mitra AI aims to address these challenges through an accessible web interface with English and Telugu language support and interactive agricultural assistance features.

This project is an initial prototype that can be expanded with verified agricultural data and AI-powered services.

🎯 Problem Statement

Farmers need accessible, understandable, and practical information to support their agricultural decisions. Language barriers and limited access to digital advisory tools can make this information harder to use.

💡 Proposed Solution

Krishi Mitra AI provides a simple web platform for exploring crop-related guidance. Its interface is designed to be accessible to users familiar with English or Telugu.

The project establishes a foundation for future development of personalized agricultural recommendations and intelligent farming assistance.

✨ Key Features

- Crop Advisor: An interactive feature for submitting crop-related information and displaying advisory results.
- English and Telugu Support: Language switching for supported interface labels.
- Plant Image Preview: Allows users to preview a selected plant image.
- Simple User Interface: Organized navigation and accessible website sections.
- Web-Based Access: Runs in a modern browser without requiring a separate mobile application.
- Expandable Architecture: Provides a starting point for integrating more advanced agricultural services.

Note: Image preview does not itself identify plant diseases. AI-based disease diagnosis and crop recommendations based on live agricultural data require appropriate implementation and validation.

🚀 Getting Started

Prerequisites

- A modern web browser
- A copy of this repository

Run Locally

2. Open the project folder.
3. Locate "index.html".
4. Open "index.html" in a browser, or use a local development server if required.

cd krishi-mitra-ai

🌍 Language Accessibility

Krishi Mitra AI includes English and Telugu language switching for supported interface text. This helps make the prototype more accessible to users who prefer Telugu.

Future versions can expand translations and include additional regional languages.
